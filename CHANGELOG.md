# Changelog

## 0.1.0 - 2026-09-15

- Initial production-oriented core.
- Semantic PASS / FAIL / DEFERRED / UNKNOWN / ERROR / NOT_APPLICABLE results.
- Immediate and eventual consistency policies.
- Durable coalesced pending checks and asynchronous evaluation.
- Distributed evaluation locks.
- State, observation, incident, fact and audit persistence.
- Incident flapping thresholds and auto-resolution.
- Event/model trigger adapters and anti-entropy sweeps.
- Evidence redaction, tenant/context adapters, metrics contract, remediation contracts.
- CLI, doctor checks, testing fake, dashboard, migrations and package tests.
